    Connect to SQL Server
    
      
    
        
    To run queries, start the app's local server instead of opening the file directly:
    
        
      
          
    1. Install Node.js (version 18 or newer).
      2. 
          
    2. Open a terminal in the app's folder and run npm install (first time only), then npm start.
      3. 
          
    3. Open http://localhost:3210 in your browser.
      4.
